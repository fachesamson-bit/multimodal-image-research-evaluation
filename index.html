Evaluation Workflow

Each evaluation instance is designed so that the hidden identity is not given away by the prompt, while the source and expected answer remain fully auditable.

01

Source

Find an authentic image of a real place, product, or media subject.

02

Provenance

Record source, license status, attribution requirements, and evidence of provenance.

03

Research

Use iterative search and visual clues to identify and independently verify the subject.

04

Transform

Create a controlled crop, occlusion, mask, or degradation while preserving useful clues.

05

Prompt

Write a concise, time-bound English prompt without revealing the target identity.

06

Rubric

Define objective, one-sentence grading criteria for the expected result.

07

Solution

Document the ground truth, research path, evidence, and expected outcome.

08

QA

Check that every claim is supported and that the obscured image remains realistic.

Multimodal Image Research & Evaluation

The project demonstrates how an authentic source image can be converted into a research-driven evaluation instance. The repository separates source material, evaluation imagery, provenance records, prompts, rubrics, and solution notes so that another reviewer can audit the workflow.

Authentic imageryProvenanceReverse-image researchCropping & occlusionPrompt designRubricsSolution notesQA

Repository structure

  • source/ — original or legitimately sourced image.
  • evaluation/ — cropped, masked, occluded, or degraded evaluation image.
  • provenance/ — source URL, license, attribution, and provenance record.
  • prompt.txt — time-bound research prompt that does not disclose the answer.
  • rubric.txt — concise objective grading criterion.
  • solution-notes.md — ground truth, research path, evidence, and expected outcome.

Current development status: the provenance stage has been established; the next demonstration stage is the controlled cropped evaluation image and its accompanying prompt, rubric, and solution notes.
