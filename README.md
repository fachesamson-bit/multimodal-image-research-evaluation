# Samson Fache — Multimodal Image Research & Evaluation Portfolio

A role-specific portfolio demonstrating skills relevant to multimodal image research, visual evaluation, provenance verification, web research, controlled image transformation, prompt design, grading rubrics, and solution documentation.

## Portfolio focus

This portfolio is designed around a complete evaluation pipeline:

1. Source an authentic real-world image.
2. Verify licensing and provenance.
3. Research the subject using multiple independent sources.
4. Create a realistic crop, occlusion, mask, or degradation.
5. Write a time-bound English prompt without revealing the target identity.
6. Create an objective one-sentence grading criterion.
7. Document the ground truth, research process, evidence, and expected outcome.
8. Perform a final QA check for factual accuracy and visual integrity.
